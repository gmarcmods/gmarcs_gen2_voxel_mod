# 0.1.38

Removes the rejected flat-yellow Persian design from 0.1.37. The original
sprite's markings and side profile are retained in a shallow 3D relief with a
continuous front and rounded back. The pedestal remains aligned with its native
collision cell. All 441 assets and unrelated profile values are preserved.

The runtime recipe/test verifies original source texels, alignment and a full
profile comparison. First/third-person and angled Gold views were inspected.
Cut, Surf camera and other 0.1.37 fixes remain included.
